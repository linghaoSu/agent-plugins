# Issue Evaluator

| Skill | Purpose |
|---|---|
| `evaluate-issue` | Build a red-capable diagnosis and fix-ready plan |
| `fix-issue` | Apply a confirmed fix and create a local commit |
| `review-pr` | Review a PR locally without GitHub mutation |
| `review-fix` | Review local changes and approved severe repairs |
| `fix-pr-comments` | Triage comments and apply selected local edits |
| `scan-issues` | Rank high-value unclaimed issues read-only |

The code-style cache is maintained internally; it has no separate public skill.
`WORKFLOW-CONTRACTS.md` owns intensity, host-neutral capabilities, modification
approval, style lifecycle, GitHub safety, and contribution etiquette.

# Agent Playbook

Focused operator workflows for repo memory, context/tool audits, explicit
implementation tournaments, and human-authorized commit/PR publication.

| Skill | Purpose |
|---|---|
| `bootstrap-project-memory` | Create or prune concise repo instructions |
| `context-audit` | Audit memory, rules, hooks, tool overlap, and verification |
| `tool-review` | Risk-review one agent-facing tool or schema |
| `implementation-tournament` | Compare explicitly requested isolated candidates |
| `commit-changes` | Create a scoped commit and optional draft PR |

Shared contracts live in `WORKFLOW-CONTRACTS.md`. Audit skills write only their
documented local reports; commit/publication requires explicit user intent.
